How it works

Huffman Coding is a lossless compression algorithm. It assigns shorter bit codes to frequent byte values and longer codes to less frequent values. The compressed file stores the original filename, frequency table, and encoded data so it can be reconstructed later. Some files that are already compressed (such as JPEG, MP4, or ZIP) may not become smaller.
